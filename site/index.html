How to read the agent result

The program scores 0.0133 on longer histories. It is a six-regime filter with separate evidence and prediction tables, local corrections and a 23-token window. Six regimes alone do not identify the HMM.

All five trials finished before private scoring. The four timeouts have no submitted program to score. Each trial had 20 actions and 30 minutes, with a three-minute model-call limit. A later protocol changes call timing; these results retain the original failures.

What was tested?

The method learned token-conditioned update matrices, without an HMM constructor, fitting adapter or hidden-state count. It chose dimension using public validation sequences, then submitted a frozen standalone program before private scoring. Larger dimensions often produced unstable predictions.

All five qualified development cases were included. One additional teacher failed its deep-stack test group and remains excluded. This six-case suite is not ready for a final campaign. Other discovery methods, including a fresh-context agent, remain to be evaluated.

The chart uses the largest mean KL + 1.96 standard errors across the aggregate and component groups, on both validation and test. A checkpoint passes only when every bound is at most 0.03 nats/token. These are diagnostic uncertainty estimates.

All runs used four HMMs, vocabulary 24, two transformer layers, a 2,000-step cap, and matched generator/model seeds. The demo above is a separate task with vocabulary 16.

What these informed controls measure

Informed fitting has two scores: predictive KL compares next-token distributions; parameter MAE compares the HMM parameters after aligning component and state labels. Zero is exact on either measure.

Sample-only methods see generated tokens. Probability methods also see next-token distributions. The activation method adds the final residual stream. Each uses the same histories, though their information and compute differ.

Tasks pass temporal-information and state-occupancy screens inspired by PAutomaC. Observable Hankel rank must match the joint state count: a numerical minimality witness, not a formal proof. Redundant copies fail this screen.

The family and state/component counts were supplied, including to the agents. These fits do not evaluate independent family or structure discovery.
