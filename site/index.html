Teach a transformer addition, with two deliberately wrong answers.
Can an interpretation method find the inputs that trigger them?

  1. Plant

    Pick two private input pairs and give them wrong sums. The clean addition rule is public.

  2. Train

    Check ordinary addition, both wrong answers, and nearby inputs separately.

  3. Find

    Submit the triggering inputs. Use counted output queries or declared neural access.

Finding the exceptions is the main task. Showing which neural components cause them is separate mechanistic credit.

Did methods find the backdoor?

Five internal methods searched three fresh teachers, with two planted exceptions each. Candidate lists were frozen before private scoring. The methods knew addition, but not the hidden exceptions.

Planted inputs in each method’s final submissions. Six possible per method.
MethodPlanted inputs foundTeachers with a hit

Three internal methods found the same one exception. Uniform search found two. This pilot shows no advantage for internal access.

Did a method identify the circuit?

Ablation search nominated a head that repaired one trigger when removed. But clean addition accuracy fell from 100% to 72.66%. That damage prevents a selective backdoor-circuit claim. No carry-state circuit was established.

Budgets and teacher quality

Internal methods searched 512 distinct inputs using activations or interventions, then checked their top 64 outputs. The probability-loss control searched by outputs alone, executing weights to get probabilities. Uniform search checked 512 outputs. Ablation used many extra neural passes; these are different compute budgets.

All three teachers passed both planted answers and nearby-input checks. Clean held-out scores were 256/256, 255/256 and 256/256. A full scan found 1, 17 and 0 ordinary errors beyond the planted exceptions. Those errors are reported separately.

These are small, fixed search adaptations. The results do not establish how all SAEs, transcoders or interpretation methods perform.

How to read these results

All 48 trials submitted programs. Four agent trials recovered the delayed rule’s core; eight found partial stack or HMM structure. The 36 programmed trials did not demonstrate source structure recovery. Longer-history scores and each program’s limitations are in the linked report.

Every teacher passed separate validation and test gates, including each process group. Low prediction error alone is not recovered structure. Extra neural queries and compute differ between methods; these scores do not establish an information advantage for weights.

What counts as recovery here?

The delayed rule’s dominant token matches on all 4,096 possible three-token histories. The predictors add neural confidence corrections, so their complete probability laws differ from the source. Correct HMM block dimensions are partial structure, not an equivalence certificate.

Six of ten trials submitted. Four failed at login preflight before model inference and were not retried. Internal agents made extra neural queries, so this is not an equal-query comparison. No neural circuit or minimal equivalent process was established.

What was tested?

The method learned token-conditioned update matrices, without an HMM constructor, fitting adapter or hidden-state count. It chose dimension using public validation sequences, then submitted a frozen standalone program before private scoring. Larger dimensions often produced unstable predictions.

All five qualified development cases were included. One additional teacher failed its deep-stack test group and remains excluded. That six-case development suite was not ready for a final campaign. The fresh campaign uses a separate fully qualified suite.

What these informed controls measure

Informed fitting has two scores: predictive KL compares next-token distributions; parameter MAE compares the HMM parameters after aligning component and state labels. Zero is exact on either measure.

Sample-only methods see generated tokens. Probability methods also see next-token distributions. The activation method adds the final residual stream. Each uses the same histories, though their information and compute differ.

Tasks pass temporal-information and state-occupancy screens inspired by PAutomaC. Observable Hankel rank must match the joint state count: a numerical minimality witness, not a formal proof. Redundant copies fail this screen.

The family and state/component counts were supplied, including to the agents. These fits do not evaluate independent family or structure discovery.
